# Sample Search Trace

This guide explains the sample response in `public/data/arad-bucharest-search.json`.
The sample runs both algorithms from Arad to Bucharest without changing the source data.

## Final Result

Both algorithms find the same optimal route:

```text
Arad -> Sibiu -> Rimnicu Vilcea -> Pitesti -> Bucharest
418 km
```

The comparison is in the search work, not the final route:

| Algorithm | Expanded | Generated | Peak frontier | Trace length |
|---|---:|---:|---:|---:|
| UCS | 13 | 14 | 4 | 13 |
| A* | 9 | 13 | 6 | 9 |

## Animation Contract

Use `trace[index]` as one animation frame. Each frame contains:

- `expanded_city`: the city removed from the priority queue;
- `expanded_cost`: its cost from the start;
- `frontier`: the queue after expansion, ordered by priority;
- `discovered`: the best-known records accumulated so far.

The first UCS frame is:

```json
{
  "expanded_city": 0,
  "expanded_cost": 0,
  "frontier": [
    { "city": 1, "cost": 75, "priority": 75 },
    { "city": 4, "cost": 118, "priority": 118 },
    { "city": 3, "cost": 140, "priority": 140 }
  ]
}
```

The first A* frame expands the same city, but its frontier priority includes the current-flow heuristic:

```json
{
  "expanded_city": 0,
  "expanded_cost": 0,
  "frontier": [
    { "city": 3, "cost": 140, "priority": 273.741213968169 },
    { "city": 1, "cost": 75, "priority": 298.597734690728 },
    { "city": 4, "cost": 118, "priority": 365.654882495184 }
  ]
}
```

## Rendering Rules

1. Draw roads from the static graph metadata.
2. Draw `frontier` nodes for the current frame.
3. Mark `expanded_city` as the active node.
4. Draw discovered parent links from each frame's `discovered` records.
5. Reveal an algorithm's final `path` only after its goal frame is reached.
6. Run the UCS and A* traces on the same timeline, using different colors.
7. Use city IDs from the JSON and names/coordinates from `lib/romaniaGraph.ts`.

Do not edit the JSON to reposition nodes or change the animation. Presentation coordinates belong in the graph metadata, while search results remain generated by Rust.
